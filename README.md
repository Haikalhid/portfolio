## Overview

Official personal portfolio website of **Muhammad Haikal Hidayat**, an undergraduate **Internet Engineering Technology** student at **Universitas Gadjah Mada (UGM)**. This platform presents my academic background, professional experience in large-scale Network Operations Center (NOC) monitoring and Data Quality Assurance, organizational leadership, and collaborative engineering projects.

### Core Focus Areas

1. **Cloud Computing** — Linux system administration, containerized workloads, and distributed cloud infrastructure.
2. **Network Operations & Engineering** — 24/7 site monitoring across Indonesia's 3T regions, cross-cluster troubleshooting, and MikroTik router configuration.
3. **Artificial Intelligence** — AI model integration for biometric access control, automation, and structured data pipelines.
4. **Cybersecurity** — End-to-end IoT security hardening, cryptographic gateway authentication, Role-Based Access Control (RBAC), and session security.

## Architecture & Web Standards

- **Semantic & Accessible HTML5** — Native `<dialog>` modal overlays, responsive Popover API navigation (`popover="auto"`), and full keyboard navigation support.
- **Modern Responsive CSS** — CSS Grid & Subgrid card alignment, Container Queries (`cqi`), Scroll-Driven Animations, and adaptive mobile-first layout with auto-hiding scroll header.
- **Interactive 3D Geometric Canvas** — Custom real-time 3D perspective geodesic icosahedron and octahedral crystal lattice rendered on HTML5 `<canvas>` with pointer-tilt physics.
- **Bilingual Support** — Instant client-side language switching between **Bahasa Indonesia (ID)** and **English (EN)**.
